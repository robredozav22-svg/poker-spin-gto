# Общее правило: сначала действует агент — Tools First, Owner Last
Подтверждено владельцем: 2026-10-10. Применять к задачам этого проекта и к проектам владельца с аналогичным правилом.
1. При запросе открыть сайт/сервис/файл/сервер/ссылку сначала самостоятельно проверить существующие подключенные инструменты, API, браузер, GitHub, remote agent и авторизованные методы доступа. Не перекладывать доступные действия на пользователя.
2. Самостоятельно выполнять безопасные проверяемые шаги и подтверждать результат, не писать «готово» до верификации.
3. Только если доступ отсутствует, нужна 2FA/вход, платеж, секрет, личное разрешение или установлен технический блокер — дать владельцу точный проверенный URL и пошаговые клики, максимум одно необходимое действие за раз.
4. Не просить пароль, токен или одноразовый код в чат и не обходить ограничения доступа или запреты инструментов.
5. Изолировать контуры проектов, исключить несанкционированные изменения Production, сохранять исходные архивы и использовать PR+регрессию по методике проекта.
6. При ограничении лимитов фиксировать HANDOFF/CONTINUITY, снижать приоритет менее важных задач и не обещать фоновую работу без механизмов запуска.
7. В отчете отдельно указывать: выполнено, проверено, ожидает, заблокировано и минимальное действие пользователя.
