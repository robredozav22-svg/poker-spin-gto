## Quality rule
Before finalizing a hand calculation, verify:
- exact cards
- known/unknown card counts
- clean vs dirty outs
- overlap between draws
- pot odds
- equity threshold
- final decision

## Chat rollover protocol
Use short lane-specific chats. At the end of a substantial session, store:
- concepts covered
- recurring mistakes
- benchmark numbers
- next exercises
- unresolved spots

A new chat should continue from these notes, not from a pasted transcript.
